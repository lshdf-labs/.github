# lshdf-labs

Independent security research lab focused on **vulnerability research**, **systems security**, **fuzzing**, and **AI security**.

## Research Areas

- Vulnerability research & exploitability analysis (userland / kernel)
- Systems security: memory safety, sandboxing, privilege separation
- Coverage-guided fuzzing: harness engineering, corpus & dictionary strategy
- AI security: LLM red-teaming, agent abuse cases, ML supply chain
